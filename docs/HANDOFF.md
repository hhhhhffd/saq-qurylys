# SAQ QURYLYS — передача проекта

Документ для нового владельца проекта: что это, в каком оно состоянии, где что лежит и что делать дальше.
Состояние на 15.10.2026. Обзор продукта и быстрый старт — в [README](../README.md); этот файл их не повторяет,
а дополняет.

## Что это и зачем

Решение кейса хакатона **Codemasters 8.0** (Усть-Каменогорск, 14–21.10.2026): мониторинг рисков в долевом
жилищном строительстве. Система собирает рекламу ЖК, фиксирует её как доказательство, находит предложения внести
деньги и считает объяснимый балл риска R1–R6 (зелёная / жёлтая / красная зона). По красной зоне создаётся
сигнальная карточка, решение по ней всегда принимает человек.

**Сроки сдачи:** публичный репозиторий GitHub, рекомендуемая отсечка — **20.10.2026 23:59**.

**Приоритет источников требований:** PDF кейса («Кейс Codemasters 8.0. SAQ.pdf») > исходное ТЗ (docx) > ТЗ v2.
Если что-то спорно — сверяться с PDF кейса. Принятые решения: [SPEC.md](SPEC.md) §1 (D17–D20 взяты из кейса),
мелкие — [OPEN_QUESTIONS.md](OPEN_QUESTIONS.md).

**Критерии жюри:** MVP и сквозной сценарий — 25, ИИ / данные / объяснимость — 20, код и GitHub — 20, питч — 20,
UX — 10, оригинальность — 5. Обязательны: тест-сценарии A/B/C, README по структуре кейса, автотесты.

## Структура кода

- `backend/app/modules/<модуль>/` — модульный монолит FastAPI: `router.py`, `service.py`, `schemas.py`,
  `tasks.py` (Celery). Модули: `objects`, `developers`, `documents`, `complaints`, `inspections`, `ads`, `nlp`,
  `risk`, `signals`, `dashboard`, `registry_sync`, `graph`, `activity`, `evidence`, `audit`, `auth`, `users`,
  `territories`, `holidays`, `settings`, `notifications`, `linked_entities`.
- `backend/app/collectors/` — сборщики (Telegram `t.me/s`, OLX, Krisha, Instagram Graph API).
- `backend/app/userbot/` — Telegram-юзербот на Telethon (SPEC §10.8), `backend/app/bot/` — бот для граждан.
- `backend/app/seed.py` — `--demo` (20 вымышленных ЖК) и `--pilot` (28 реальных ЖК Усть-Каменогорска).
- `backend/alembic/versions/` — миграции `0001`…`0005`, текущая голова — `0005`.
- `frontend/src/features/<раздел>/` — `map`, `objects`, `ads`, `signals`, `graph`, `sources`, `admin`, `login`,
  `kit` (витрина `/_kit` в dev). API-типы — `frontend/src/api/types.ts`, переводы — `frontend/src/i18n/locales`.
- `frontend/e2e/` — Playwright e2e (44 теста, `pnpm e2e`; админским нужен `SAQ_ADMIN_PASSWORD`).
- `scripts/verify_case_scenarios.py` — проверка сценариев A/B/C на запущенном стеке с демо-данными.

## Правила, которые важно не нарушить

- **Не обвинять реальные компании.** В README, скриншотах и видео — только вымышленные ЖК (помечены «ДЕМО»,
  БИН `99…`, телефоны `+7 700 000 …`, ссылки `example.invalid`). Реальные данные пилота — без баллов и оценок.
- **Неизвестно ≠ нарушение.** «Нет данных» даёт 0 баллов и уходит в «Нужна проверка»; R1 — только когда оба
  основания проверены и не найдены.
- **ИИ и автосбор не влияют на балл без человека**: гипотезы LLM и автопривязки публикаций засчитываются только
  после подтверждения аналитиком (OPEN_QUESTIONS 27–29).
- **Доказательства неизменяемы**: `evidence`, `audit_log`, `risk_factor_change`, `ad_post_version` защищены
  триггерами от UPDATE/DELETE/TRUNCATE, файлы — в бакете MinIO с Object Lock. Не обходить.
- OLX/Krisha закрыты WAF; браузерный User-Agent разрешён **только для демо** с редкими запросами (OPEN_QUESTIONS
  36, 40). TikTok автосбором не берётся (31). Сертификат data.gov.kz не обходим (41).
- Секреты только в `.env` (в git не попадает). `JWT_SECRET` обязателен, не короче 32 символов.

## Нюансы окружения

- Разработка шла в WSL2 + Docker Desktop. Ollama внутри WSL недоступна по `host.docker.internal` (ведёт в Windows):
  в `.env` указывать `OLLAMA_URL=http://<IP WSL>:11434` (`hostname -I`), Ollama запускать как
  `OLLAMA_HOST=0.0.0.0:11434 ollama serve`, модель `qwen3.5:9b-q6k`. После перезагрузки ПК Ollama поднимать вручную.
- Юзерботу нужен **свой** отдельный номер Telegram и свои `TELEGRAM_API_ID`/`TELEGRAM_API_HASH`
  (https://my.telegram.org), затем вход по QR — см. README. Сессия прежнего владельца не передаётся.
- Боту граждан нужен свой токен от @BotFather в `TELEGRAM_BOT_TOKEN`.
- Файл открытого набора Казреестра кладётся в `data_tmp/` (в git не попадает) и импортируется
  `python -m app.modules.registry_sync.ashyq` (DATA_SOURCES.md, раздел h).
- Образ MinIO — сборка сообщества `alpine/minio` (официальных образов больше нет).
