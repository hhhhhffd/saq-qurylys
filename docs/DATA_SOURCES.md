# SAQ QURYLYS — как получить входные данные там, где нет API

Пилот: г. Усть-Каменогорск (Өскемен), ВКО. Проверка URL выполнена 2026-10-13 (UTC+5) из среды сбора.
Обозначения: **[OK]** — страница открывалась (HTTP 200); **[SPA]** — открывается как оболочка, содержимое грузится скриптом, текст не читался; **[НЕТ]** — не открылась из среды сбора (таймаут/403); **[?]** — сведения из результатов поиска, прямой проверки не было.

## 0. Общие правила фиксации доказательств

1. Скриншот делать целиком вместе с адресной строкой и системными часами (время в зоне Asia/Almaty, UTC+5 — единый пояс Казахстана с 2024-03-01). Дополнительно — «Печать в PDF».
2. Имя файла: `YYYY-MM-DD_HHMM_<источник>_<объект>.png/pdf`; в журнале — URL, дата-время, кто снял, SHA-256 файла.
3. Если снимается ответ API/JSON — сохранять сырой ответ как есть + дату запроса; не редактировать.
4. Персональные данные (телефоны, e-mail, ФИО физлиц) в базу SAQ без необходимости не переносить. В `objects_public.json` контакты застройщиков намеренно не включены.
5. Значения «самодекларации» (krisha.kz, сайты застройщиков) отличать от записей государственных систем; в карточке объекта всегда хранить `source_url` и дату снятия.

## (c) Кадастровый номер и целевое назначение земли

- **Источник номера:** карточка объекта на homeportal.kz (поле «кадастровый номер», пример формата `05-085-091-1658`), разрешение/ДДУ.
- **Публичная кадастровая карта АИС ГЗК:** https://www.aisgzk.kz/aisgzk/ru/content/maps [OK] (оператор — Управление земельного кадастра и АИС ГЗК НАО «Правительство для граждан»). Режим «Поиск кадастрового участка»; слои: «Кадастровая карта», «Кадастровая карта (Спутник)», «Охранные зоны», «Карта земельных отводов» и др. (https://www.aisgzk.kz/aisgzk/ru/content/maps?type=cosmos и т.п.).
- **Что видно:** границы участка и справочные сведения по выбранному участку (состав полей — проверить вручную: сайт — приложение на JS, поля не просматривались).
- **Автоматизация:** публичного API нет. На сайте указана «Форма заявки для доступа к РБД АИС ГЗК посредством aisgzk.kz» — доступ к БД для организаций по заявке (**[?]** условия не изучались).
- **Процедура:** открыть карту → «Поиск» по кадастровому номеру → выбрать участок → скриншот с границей, номером, площадью и целевым назначением (если отображается) вместе с адресной строкой. Официальный документ о целевом назначении — у собственника/землепользователя либо через ЦОН/egov (**[?]**).

## (e) Регистрация ДДУ

- **Система:** Единая информационная система долевого участия «Казреестр» — https://qazreestr.kz/ [OK, страница входа, требуется авторизация]. По разъяснению КЖК (14.02.2024, https://khc.kz/ru/press-center/news/458/ [OK]): ДДУ по типовой форме регистрируется в Казреестре; при успешной регистрации формируется выписка, которую застройщик обязан передать дольщику.
- **Что видит дольщик:** личный кабинет на homeportal.kz и в eGov (номер и дата ДДУ, стоимость доли, компания).
- **Услуга на egov.kz:** «Выдача выписки об учетной записи договора о долевом участии в жилищном строительстве» — https://egov.kz/cms/ru/services/pass671-7_mir **[?]** (ссылка из поиска, страница не открывалась).
- **Для офицера:** доступ к Казреестру имеют регистрирующие органы (МИО) по своим учётным записям — **[?]** условия доступа для МИО/платформы в открытых источниках не найдены. Публичного API нет. Карточка homeportal.kz показывает агрегаты «квартир / продано» (данные застройщика).
- **Процедура:** (1) письменный запрос в акимат о числе зарегистрированных ДДУ по каждому ЖК на дату; (2) либо скриншоты/выгрузка с экрана Казреестра под учётной записью органа; (3) сопоставить с «продано» в карточке homeportal.kz — расхождение отмечать без выводов.

## (f) Жалобы граждан (e-Otinish)

- **Портал:** https://eotinish.kz/ru [OK] — для граждан; в категорию «Земля. Бизнес. Налоги» входят вопросы строительства. Публичного API нет **[?]**.
- **Доступ МИО:** акиматы — получатели обращений в системе; детали доступа МИО/выгрузок и интеграции с внешними системами в открытых источниках **не найдены** — уточнить у администратора e-Otinish акимата / в уполномоченном министерстве (письмом).
- **Практика для платформы:** (1) запросить у акимата ежеквартальный отчёт по обращениям с темой «долевое строительство» (номер, дата, ЖК, застройщик, статус; без персональных данных); (2) в SAQ вносить жалобу вручную: номер обращения, дата, объект, суть, ссылка на ответ органа; (3) скриншот карточки обращения — только без ПДн заявителя.
- **Параллельные каналы:** жалоба по жилому дому в КЖК https://khc.kz/ru/complaint/ [OK], колл-центр 1408, чат-бот https://homeportal.kz/ru/chatbot [OK].
