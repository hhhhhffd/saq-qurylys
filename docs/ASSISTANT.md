# SAQ ASSISTANT — помощник сотрудника

Боковая панель «Спросить ИИ» (по образцу Ask AI в панели Cloudflare). Помощник объясняет, как работать в SAQ,
отвечает по руководству сотрудника (RAG), учитывает открытую страницу и читает живые данные через инструменты
только на чтение и только в пределах прав и территории пользователя. Сам ничего не меняет.

## Решения

| # | Вопрос | Решение |
|---|--------|---------|
| 1 | Модель | Любой OpenAI-совместимый `/chat/completions`: по умолчанию локальная Ollama (`qwen3.5:9b-q6k`, можно `qwen3.5:4b`), при желании Gemini, Groq и т. п. сменой `ASSISTANT_BASE_URL`/`ASSISTANT_API_KEY`/`ASSISTANT_MODEL`. |
| 2 | База знаний | Отдельное руководство сотрудника `backend/app/modules/assistant/guide/*.md` (лежит в backend, чтобы попасть в образ). Dev-документы (SPEC, UI, VISION_PLAN) не индексируются. |
| 3 | Поиск по базе | BM25 по леммам (`app.modules.nlp.text.tokenize`, pymorphy3), индекс в памяти процесса. Эмбеддинги не нужны: корпус маленький, а Groq эмбеддингов не даёт. |
| 4 | История диалогов | Только в браузере (localStorage, ключ на пользователя), без таблиц и миграций. |
| 5 | Права | Инструменты повторяют права HTTP API: реестр, объявления и сводка — только admin и mio_officer; карточки — все роли с той же видимостью, что `card_stmt`. Территория — через `build_scope`. Чужой объект — «не найден». |
| 6 | Недоверенные данные | Тексты объявлений и прочие данные из инструментов — данные, а не инструкции; инструменты только читают, поэтому вред от prompt injection ограничен неверным ответом. |

## Настройки (`.env`)

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `ASSISTANT_ENABLED` | `false` | Без неё маршрутов `/api/v1/assistant/*` нет (404), кнопка в шапке скрыта. |
| `ASSISTANT_BASE_URL` | `http://host.docker.internal:11434/v1` | База OpenAI-совместимого API. Gemini: `https://generativelanguage.googleapis.com/v1beta/openai`, Groq: `https://api.groq.com/openai/v1`. |
| `ASSISTANT_API_KEY` | пусто | Ключ провайдера; пусто — заголовок `Authorization` не отправляется. |
| `ASSISTANT_MODEL` | `qwen3.5:9b-q6k` | Имя модели у провайдера. |
| `ASSISTANT_REASONING_EFFORT` | `none` | Передаётся как `reasoning_effort`; пусто — поле не отправляется. `none` выключает «размышления» qwen3.x в Ollama. **Для Groq и Gemini обычно нужно оставить пустым**: модели без управляемых размышлений отвечают HTTP 400 (текст ответа пишется в лог api). |
| `ASSISTANT_TIMEOUT_S` | `120` | Таймаут одного запроса к модели. |
| `ASSISTANT_MAX_TOOL_ROUNDS` | `4` | Сколько раз подряд модель может вызвать инструменты в одном ответе. |

## API

### `GET /api/v1/assistant/config`

Любой вошедший пользователь. `{"enabled": true, "model": "qwen3.5:9b-q6k"}`. Если модуль выключен — 404 (как `/vision/config`).

### `POST /api/v1/assistant/chat`

Любой вошедший пользователь. Тело:

```json
{
  "messages": [{"role": "user", "content": "Как отправить карточку в ГАСК?"}],
  "page": {"path": "/objects/12", "entity": {"type": "object", "id": 12}},
  "language": "ru"
}
```

- `messages` — 1…20 сообщений, `role` ∈ `user|assistant`, `content` 1…4000 символов, последнее — от `user`.
- `page` — необязательно. `path` — путь страницы без query (до 200 символов). `entity.type` ∈ `object|signal|ad|vision_session`.
- `language` ∈ `ru|kk` — язык ответа.

Ошибки до начала стрима — обычный JSON `{"detail": {"code", "message"}}` (401, 422). Иначе `200 text/event-stream`,
кадры `data: <json>\n\n`, по одному событию на кадр:

| `type` | Поля | Когда |
|---|---|---|
| `sources` | `sources: [{id, title, page}]` | Сразу: разделы руководства, найденные по вопросу. `page` — путь страницы SAQ, к которой относится раздел, или `null`. |
| `tool` | `name`, `label` | Модель вызвала инструмент; `label` — что делается, на языке ответа («Ищу объекты: Нурлы»). |
| `delta` | `text` | Очередной кусок ответа (markdown). |
| `error` | `code`, `message` | Сбой посередине: `llm_unavailable`, `llm_bad_response`, `too_many_tool_rounds`, `internal_error`. После него поток закрывается. Поток без `done` и `error` — обрыв связи, интерфейс показывает ошибку. |
| `done` | — | Ответ закончен. |

Ссылки в ответе — обычные markdown-ссылки на пути SAQ (`[ЖК Тест](/objects/12)`, `/signals/5`, `/ads?ad=7`, `/work`).

## Инструменты модели

| Имя | Кому | Что возвращает |
|---|---|---|
| `search_guide(query)` | все | Разделы руководства (дополнительный поиск, если найденного сразу мало). |
| `search_objects(query, zone?)` | staff | До 10 объектов: id, код, название, застройщик, район, балл, зона, ключевой статус, ссылка. |
| `get_object(object_id)` | staff | Паспорт объекта, последний балл, зона, причины зоны, факторы риска, «нужна проверка», ссылка. |
| `list_signals(status?, object_id?)` | все (видимость `card_stmt`) | До 10 карточек: номер, объект, статус, адресат, срок, просрочена ли, ссылка. |
| `search_ads(query?, object_id?, status?)` | staff | До 10 публикаций: площадка, дата, объект, схемы оплаты, статус, фрагмент текста, ссылка. |
| `work_summary()` | staff | Счётчики зон по территории пользователя и число карточек по статусам. |

## Поведение и ограничения

- Последний разрешённый раунд (`ASSISTANT_MAX_TOOL_ROUNDS`) отправляется модели без инструментов, с просьбой ответить по уже полученным данным; `too_many_tool_rounds` — только если модель всё равно просит инструмент.
- Ответ, обрезанный провайдером по длине (`finish_reason: length`), получает в конце пометку «Ответ обрезан».
- Внешние ссылки в ответах не кликабельны (показывается домен): ссылку могла подсунуть публикация через prompt injection. Кликабельны только пути SAQ.
- Каждый идущий ответ занимает поток пула FastAPI (синхронный httpx, по умолчанию 40 потоков на процесс), пока модель отвечает. Для пилота это не ограничение, а локальная Ollama и так обслуживает запросы по очереди; при десятках одновременных диалогов нужен отдельный пул или async-клиент.
- nginx держит `/api/v1/assistant/` до 300 с без буферизации (обычный `/api/` — 120 с).
