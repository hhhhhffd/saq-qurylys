# Открытые вопросы

Незначительные вопросы, по которым принято решение по умолчанию. Работа продолжается; если решение не устраивает — поправить здесь и сообщить.

| # | Вопрос | Принятое решение |
|---|--------|------------------|
| 1 | Можно ли смешивать реальные ЖК/застройщиков с выдуманными рисками в демо-данных? | Нет: демо-объекты (`--demo`) — только вымышленные названия и БИН. Реальные публичные сведения о ЖК (если найдены) идут отдельным CSV для импорта, без каких-либо отметок о нарушениях: зону система посчитает сама по внесённым данным. Иначе «красная» метка у реального застройщика в демо — риск диффамации. |
| 2 | Официальный образ `minio/minio` больше не публикуется (upstream в архиве). | В compose — закреплённая сборка `alpine/minio:RELEASE.2025-10-15T17-29-55Z`. Бэкенд использует только S3 API + Object Lock, на проде можно заменить на любое S3-совместимое хранилище с Object Lock правкой `S3_*`. |
| 3 | Защита входа от перебора. | В v1 нет. До прода: `limit_req` на `/api/v1/auth/login` в nginx + аудит неудачных входов. |
| 4 | Отзыв JWT при смене пароля. | В v1 нет — токен живёт `JWT_TTL_MINUTES` (480). До прода: версия токена в `app_user`. |
| 5 | Неизменяемость на уровне БД обходится суперпользователем. | В dev приложение ходит в БД владельцем. На проде — отдельная роль приложения без UPDATE/DELETE на `evidence`, `audit_log`, `risk_factor_change`; S3-ключ без права обхода governance. |
| 6 | Видимость застройщиков между регионами. | Поиск по полному БИН находит застройщика из любого региона (чтобы привязать к объекту), включая руководителя и телефоны. |
| 7 | Журнал действий для `mio_officer`. | По всем сигнальным карточкам своей территории (а не только «своим»). |
| 8 | `dsu_permit` | = разрешение на привлечение денег дольщиков (ДДУ/дольщики). |
| 9 | Перевод на казахский (UI). | Сделан, требует вычитки носителем. Казахских вариантов в словаре рисковых формулировок пока нет. |
| 10 | Защита от ухода со страницы с несохранёнными правками сигнальной карточки. | Только `beforeunload` + панель «Сохранить/Отменить»; полноценный guard требует перехода на data router. |
| 11 | Жилищный портал АО «КЖК» (homeportal.kz) отдаёт реестр объектов долевого строительства через недокументированный публичный API (`api.homeportal.kz`). | Используем для пилота: снимок от 2026-10-13 в `data/pilot/`, плюс команда синхронизации (выключена по умолчанию). Для регулярного использования нужно письменное согласование с АО «КЖК» — до этого автосинхронизация не включается. |
| 12 | Основание «Участие БВУ» в реестре КЖК не имеет отдельного типа документа в модели. | Записывается как `dsu_permit` (разрешение МИО выдаётся при всех трёх основаниях) с основанием в примечании. Гарантия КЖК → `guarantee`. |
| 13 | ЖК с krisha.kz, которых нет в реестре КЖК. | Документ `dsu_permit` со статусом `checking` («требуется ручная сверка»), а не `not_found`: отсутствие в выгрузке не доказывает отсутствие разрешения. Зона таких объектов — жёлтая до ручной сверки. |
| 14 | Календарь 2027 и границы районов. | Календарь 2027 — расчётный по закону, без официальных переносов (перепроверить в декабре 2026). Районы — приблизительные полигоны (официальных границ в открытых данных нет), только для фильтра. |
